# Leon - Creative Agency Template

A modern and responsive landing page for a creative agency, built from scratch using HTML & CSS.

This project is a practice on building a complete website layout, from header and navigation to services, portfolio and contact sections.

## Features
- Responsive design for mobile and desktop
- Navigation with dropdown menu
- Landing section with hero image
- Features section
- Services section
- Portfolio section
- About section
- Contact section

## Technologies Used
- HTML5
- CSS3
- Font Awesome for icons
- Google Fonts

## How to Run
1. Download or clone the project
2. Open index.html in your browser
   
## Project Sections
- Header: Contains the logo and navigation menu
- Landing: Hero section with main title and image
- Features: Shows 3 main features of the agency
- Services: Displays the services like Graphic Design and Web Design
- Portfolio: Shows our previous projects with images
- About: Information about the agency and its goals
- Contact: Email and social media links to contact us
